# databricks-platform-airflow3

Runs `contoso-data-product` on **databricks-emulator (or a real Databricks workspace) orchestrated by an external Apache Airflow 3** — the Databricks counterpart of [`fabric-platform-airflow3`](https://github.com/calvinchengx/fabric-platform-airflow3).

Distinct from [`databricks-platform-jobs`](https://github.com/calvinchengx/databricks-platform-jobs), which drives the same product through Databricks' own Jobs. Same product, two orchestrators.

The platform installs the product and knows no Contoso.

## Status

**Not started.** This repository exists so the family index is complete;
it holds no platform yet. See the [family layout](https://github.com/calvinchengx/contoso-data-product#readme).
